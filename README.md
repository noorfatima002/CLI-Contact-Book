# CLI-Contact-Book
A Python-based command-line contact management system designed to efficiently manage personal contact information. The application provides a simple, menu-driven interface for adding, viewing, searching, updating, and deleting contacts, with data persistence through CSV file handling.

# Key Features
Add, view, search, update, and delete contacts Partial-name search functionality CSV-based data storage and retrieval Automatic data persistence Input validation and basic error handling Modular, function-based program structure

# Technologies
Python CSV File Handling VS Code

# Purpose
Developed to strengthen practical Python programming skills, including functions, loops, conditional statements, lists, dictionaries, file handling, and modular programming.
